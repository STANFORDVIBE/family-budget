# Family Budget

Приложение для Windows для личного и семейного бюджета. Работает без интернета и без регистрации,
все данные хранятся только на вашем компьютере.

## Возможности

- Личное и семейное пространства, данные не смешиваются.
- Счета и карты в разных валютах, переводы между ними, кредитные карты.
- Расходы, доходы, возвраты и корректировки. Обычная покупка добавляется за несколько секунд (Ctrl+N).
- Бюджеты на месяц с лимитами по категориям и предупреждением на 80%.
- Регулярные платежи: приложение напоминает о них, а провести платёж решаете вы.
- Цели накоплений с прогрессом и рекомендуемым пополнением в месяц.
- Аналитика: графики, сравнение месяцев, переход к операциям по клику.
- Резервные копии: автоматически раз в день и вручную, восстановление в один клик.
