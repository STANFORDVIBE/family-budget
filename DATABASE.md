# База данных

SQLite, файл `family-budget.db` в `%APPDATA%\com.familybudget.app\`. Схема — `src-tauri/migrations/*.sql`,
применяются по порядку при запуске (`db/migrations.rs`); версия — в `schema_migrations`. Применённую миграцию
никогда не меняем — только добавляем новую. База новее приложения не открывается (`unsupported_version`).

## Соглашения

- Ключи — UUID v7 (текст). Деньги — `INTEGER` в минимальных единицах. Курсы — точный десятичный `TEXT`.
- Даты событий — `TEXT 'YYYY-MM-DD'`, технические метки — unix-миллисекунды.
- Синхронизируемые строки: `version` (растёт при каждом изменении), `updated_at`, `deleted_at` (мягкое удаление).
- У финансовых таблиц есть `workspace_id`.

## Таблицы

| Таблица | Назначение |
|---|---|
| `users` | Локальный пользователь (в 1.0 один) |
| `currencies` | Справочник ISO 4217: код, название, символ, знаков после запятой |
| `workspaces` | Пространства: `personal` / `family`, основная валюта |
| `workspace_members` | Участники: роль owner/admin/member/viewer, статус |
| `accounts` | Счета: тип, валюта, начальный баланс, кредитный лимит, иконка, цвет, активность |
| `exchange_rates` | Ручные курсы «валюта → основная» на дату, один на день |
| `categories` | Категории доходов/расходов, один уровень подкатегорий, скрытие |
| `transactions` | Заголовок операции: тип, статус posted/pending, дата, категория, участник, создатель |
| `transaction_entries` | Проводки: счёт, роль (main/transfer_out/transfer_in/fee), сумма со знаком в валюте счёта, сумма в основной валюте, курс, дата и источник курса |
| `transfers` | Детали перевода: обе суммы и валюты, курс, комиссия |
| `budgets` / `budget_limits` | Месячный бюджет и лимиты по категориям |
| `recurring_rules` | Регулярные платежи: сумма, счёт, категория, интервал, следующая дата, окончание, статус |
| `goals` / `goal_contributions` | Цели и пополнения (со ссылкой на перевод, если деньги реально перемещены) |
| `app_settings` | Настройки (ключ → JSON) |
| `audit_log` | Журнал изменений: кто, когда, действие, старое и новое значение |
| `sync_metadata` | Отслеживание локальных изменений для будущей синхронизации |

## Ключевые правила и индексы

- Баланс счёта = `accounts.initial_balance_minor + SUM(transaction_entries.amount_minor)` по операциям
  `status = 'posted' AND deleted_at IS NULL`. Отдельно баланс не хранится.
- `ux_tx_recurring (recurring_rule_id, recurring_occurrence)` — одно наступление платежа → максимум одна операция.
- `ux_rates_day`, `ux_budgets_month`, `ux_budget_limits` — уникальность среди неудалённых строк.
- `base_amount_minor` может быть `NULL` только у ожидающей (pending) операции без известного курса; проверка
  целостности (`check_integrity`) ловит нарушение.

## Проверка целостности

`PRAGMA integrity_check`, `foreign_key_check` и инварианты учёта: у проведённых проводок есть сумма в основной
валюте, у каждой операции есть проводки, переводы сбалансированы в основной валюте, проводки не выходят за своё
пространство.
