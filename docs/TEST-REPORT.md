## Что проверяется

**Ядро (Rust, на настоящей SQLite):** доходы, расходы, возвраты и корректировки; переводы, в том числе
между валютами и с комиссией (не попадают в статистику); исторические курсы; кредитные карты; повторная
отправка не создаёт дубль; бюджеты (80%, перерасход, подкатегории, прогноз по темпу за 30 дней); регулярные
платежи (одна операция на дату, без автосписания); цели (пополнение — не расход); изоляция личного и семейного
пространств; удаление категорий и счетов с историей; журнал изменений и метаданные для синхронизации;
резервные копии (туда-обратно, мусорные файлы, попытки подсунуть чужой путь, автокопии и их чистка); экспорт CSV.

**UI (Playwright → настоящий `family-budget.exe`):**

| Файл | Сценарий |
|---|---|
| `basics.spec.ts` | первый запуск, счёт, расход, данные на месте после перезапуска |
| `finance.spec.ts` | переводы с комиссией, возврат, корректировка, поиск, правка, удаление и отмена; валютный счёт и курс |
| `family.spec.ts` | личное и семейное пространства не смешиваются, участники, выбор пространства переживает перезапуск; третье пространство |
| `planning.spec.ts` | лимиты 80% и перерасход, переход к операциям; регулярный платёж ждёт подтверждения и не дублируется; цели |
| `analytics.spec.ts` | итоги, доли категорий, переход из категории к операциям, сравнение с текущим месяцем |
| `reliability.spec.ts` | копия, экспорт CSV и JSON, восстановление, проверка целостности; повреждённая база → экран восстановления → данные из копии |

## Найдено и исправлено при тестировании

- Прогноз на конец месяца в начале месяца давал абсурдные числа — теперь считается по темпу трат за 30 дней.
- Аналитика за год показывала сравнение и историю по будущим месяцам — теперь до сегодняшнего дня.
- После восстановления копии сбрасывались папка копий и «последняя копия» — теперь сохраняются.
- Меню пространств не открывалось сразу после горячей клавиши.
- Проценты обрезались (16,6 % вместо 16,7 %).
- Библиотека графиков не работала с защитой Tauri от подмены прототипов — заменена своими SVG-графиками.

## Не покрыто автотестами

Нативные диалоги Windows (в e2e подменяются), установка/удаление через NSIS, работа на Windows 11 и при
масштабе экрана 150%+ — проверить руками.
