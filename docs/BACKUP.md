# Резервные копии

Все данные лежат в одном файле `%APPDATA%\com.familybudget.appamily-budget.db`.

## Как копии создаются

- **Автоматически** — раз в день при работе приложения (`auto-*.fbbak`). Хранится 20 последних, число
  меняется в «Настройки → Резервные копии».
- **Вручную** — кнопка «Создать копию» (`backup-*.fbbak`). Такие копии сами не удаляются.
- **Перед восстановлением** — приложение сохраняет текущее состояние (`before-restore-*.fbbak`),
  так что любое восстановление можно отменить.

По умолчанию копии лежат в `%APPDATA%\com.familybudget.appackups`. Лучше выбрать папку на другом диске
или в синхронизируемой папке (OneDrive, Яндекс Диск): «Настройки → Резервные копии → Выбрать папку».

## Как восстановить

1. «Настройки → Резервные копии».
2. Напротив нужной копии — «Восстановить» (или «Восстановить из файла…», если копия лежит в другом месте).
3. Подтвердить. Данные заменятся данными копии, прежнее состояние сохранится как `before-restore-*`.

## Если приложение пишет «Не удалось открыть базу данных»

Файл базы повреждён. Нажмите «Восстановить из резервной копии» и выберите последнюю копию `.fbbak`.
Повреждённый файл не удаляется — он остаётся рядом под именем `broken-*.db`.

## Перенос на другой компьютер

Установите Family Budget на новом компьютере, скопируйте туда файл копии и восстановите его через
«Восстановить из файла…».

## Проверка

«Настройки → Проверка целостности → Проверить базу» проверяет файл SQLite, связи между записями и согласованность проводок (переводы сходятся, у каждой операции есть проводки).
